# VulkanSandbox

Small sandbox engine built on top of [my Vulkan framework](https://github.com/hevezolly/VulkanEngine) (to poke around and explore its possibilities).

The sandbox features
- depth pre-pass
- simple shadowmaps
- pbr rendering with Beckmann brdf model (Beckmann specular + simple Lambertian diffuse)
- diffuse and specular IBL cubemaps baking
- specular BRDF lookup for the IBL
